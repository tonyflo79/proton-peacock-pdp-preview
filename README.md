# Proton Peacock PDP — Preview

Mid-to-high fidelity design preview for the Proton Sports Series Three "Project Peacock" product detail page.

This is a **staging preview only** — a React + Babel-from-CDN prototype intended for stakeholder review of layout, typography, color, and copy. It is not production code.

## Live preview

Served via GitHub Pages — see the repo's Pages settings for the URL.

## Local preview

Open `index.html` directly in a browser. No build step.

## Files

| File | Purpose |
|---|---|
| `index.html` | Entry point; boots React + Babel from CDN |
| `proton-tokens.css` | Design tokens (color, type, spacing) — dark + light themes |
| `proton-copy.jsx` | Locked copy for all 12 PDP sections |
| `wf-shared.jsx` | Shared atoms (Slot, Eyebrow, Rule, ChipGroup, Nav, Footer) |
| `wf1-polished.jsx` | Full 12-section PDP component |
| `assets/` | Real product photography (3 shots); remaining slots are annotated placeholders |
